# VANTA Meet Scout

Mobile-friendly static scouting dashboard for FTC Team 31000, Orlando Robotics Meet 1, November 14, 2026.

Open `index.html` directly or deploy this folder to GitHub Pages or Vercel. No build tools required.

Includes five scheduled matches, alliances, team details, autonomous and TeleOp scouting notes, GitHub searches, website links, and JSON export/import. Data is stored locally on each browser, not synced. Verify schedule updates on the official FIRST website.
